# Neon Player

یک موزیک‌پلیر اندروید Native برای درس موبایل، با UI تیره و Neon و بدون وابستگی خارجی.

## امکانات

- اسکن خودکار آهنگ‌های موجود روی گوشی
- درخواست مجوز مناسب برای Android 13 به بالا و نسخه‌های قدیمی‌تر
- پخش، توقف، آهنگ بعدی و آهنگ قبلی
- Shuffle و Repeat
- نوار پیشرفت و زمان آهنگ
- جست‌وجو بر اساس نام آهنگ یا خواننده
- ویژوالایزر متحرک هنگام پخش
- طراحی RTL و متن فارسی

## اجرا

1. پروژه را با Android Studio باز کن.
2. اگر Android Studio خواست Gradle/Android Gradle Plugin را Sync کند، تایید کن.
3. برنامه را روی گوشی یا Emulator اجرا کن.
4. بعد از باز شدن برنامه، اجازه دسترسی به فایل‌های صوتی را بده.

اگر روی Emulator تست می‌کنی، چند فایل mp3 داخل حافظه Emulator کپی کن تا در لیست نمایش داده شوند.
